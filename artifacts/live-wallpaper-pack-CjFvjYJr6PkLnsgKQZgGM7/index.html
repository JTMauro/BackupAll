Lively Wallpaper (free)

  1. Install Lively Wallpaper from the Microsoft Store or rocksdanister.com/lively.
  2. Unzip live-wallpapers.zip into a folder you'll keep, such as Documents\Wallpapers.
  3. In Lively, click + Add Wallpaper and pick an .html file, or drag the file onto the Lively window.
  4. Click the new tile to set it. With several monitors, choose which screen it goes on.
  5. For Plexus and Koi Pond, turn on Settings → Wallpaper → Wallpaper Input → Mouse.

Wallpaper Engine (Steam)

  1. Open Wallpaper Engine and click Wallpaper Editor at the bottom left.
  2. Choose Create Wallpaper and select one of the .html files.
  3. Give it a title, then use File → Apply wallpaper.

Tune a scene

  1. Speed: everything now runs at half speed. For a slider, drag a zip from the lively folder into Lively, then right-click → Customise → Animation speed.
  2. Or open the file in Notepad and change pace in the CFG block at the top.
  3. Lower fps to 30 on laptops to save battery. Event Horizon is the most demanding scene.
  4. Both apps pause the wallpaper while a game or full-screen app is running.
