For the chat developers

Ben's page exposes one object. The AI's reply only needs a category id (find, help, fix, access, delete…) next to its text; without one, Ben reads the words himself.

Ben.express('aha')            // set an expression
Ben.gesture('nod')            // nod, shake, wink, blink
Ben.react({ intent: 'fix', text })      // a category id: find, help, fix, access...
Ben.say(text)                 // move the mouth while text appears
Ben.list()                    // all expression names
