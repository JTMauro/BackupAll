Train your own voice

Read each sentence aloud. Voice Studio listens to every take and checks what it has captured: pitch range, questions, the main vowel sounds and hiss sounds like "s" and "sh". It only asks for more sentences when something is missing, and it asks you to redo a take that was too quiet, distorted or noisy.

Voice Studio server

The server is the engine. It renders speech into clips, speaks in your own voices, searches the internet for text and audio, and lets other apps use everything here through its API.

Not connected

Start the server

Unzip voice-studio-project.zip, then double-click the starter for your computer:

Windowsstart-windows.bat
Macstart-mac.command (first time: right-click ▸ Open)
Linux./start-linux.sh

The first run installs what it needs: Python packages, plus the eSpeak NG speech engine and ffmpeg if they're missing. Then it opens this studio at http://localhost:8000, already connected. Keep that window open while you use it.

Use it from other apps

POST /v1/ttsSpeak text, or pass read_from to find text on the internet. Options: voice_id, pitch, speed, volume, sentence_pause, accent, tone, format.
POST /v1/convertRe-voice an audio file into a stored voice (with speed and pitch)
GET /v1/voicesList voices · POST /v1/voices/design create · PATCH /v1/voices/{id} change · DELETE remove
POST /v1/voices/cloneMake a voice from a recording (consent=true) · POST /v1/voices/{id}/train adds more takes
GET /v1/text?q=Find text to read: a search phrase or a web address
GET /v1/audio/search?q=Search free internet audio · GET /v1/audio/fetch?url= downloads it
POST /v1/audio/encodeConvert audio to wav, mp3, ogg or flac
GET /v1/catalogEvery accent, tone, gender and age option
