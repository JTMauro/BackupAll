This is the source package. On a PC with the Cydcor code-signing certificate, double-click BUILD CYDFTP.cmd to make signed installers for everyone. The steps are below.

Make the signed Windows installer

  1. Unzip cydftp-source.zip on a Windows PC that has the Cydcor code-signing certificate. If the certificate is on a USB token, plug it in.
  2. Double-click BUILD CYDFTP.cmd. The first time, it installs Python 3.13, Inno Setup and the Windows signing tools if they're missing, then builds and self-tests the app.
  3. Click Yes when Windows asks to allow changes. A second window signs everything; press Enter when it says it's done.
  4. The Output folder opens with CydFTP-0.1.0-release.zip: both signed installers, checksums and DEPLOY.md, ready to share.

Prefer to run it without building? In the cydftp folder:

python -m venv .venv .venv\Scripts\pip install -r requirements.txt .venv\Scripts\python run.py

What's on the drive

Transfer
SFTP, FTPES, implicit FTPS, FTP. Parallel queue with automatic retry and resume.
Vault
AES-256-GCM encryption, with the key derived from your master password by scrypt.
OpenPGP
Create, import and export keys. Encrypt, decrypt, sign and verify. Works with GnuPG and Kleopatra.
SSH keys
Ed25519, RSA and ECDSA. Saves PuTTY .ppk v2/v3, OpenSSH and PEM files.
FileZilla
Imports sites, folders, saved passwords and the key files the sites use.
Needs
Windows 10/11, macOS or Linux. Building needs Python 3.11 to 3.13.
