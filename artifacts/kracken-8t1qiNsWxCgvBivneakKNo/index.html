Clue Finder

The fastest unlocks come from knowing something about the owner — not raw compute. Interview the client with these, type the answers, and send them straight into the attack. Every field is optional; more is better.

Or find it without cracking

Often the password — or an already-unlocked copy — is sitting somewhere. Walk this list with the client:

  • Search their email for the file name and words like "password", "pwd", "the password is".
  • OneDrive / SharePoint / Google Drive version history — an earlier version may predate the lock.
  • Their password manager (1Password, LastPass, Bitwarden, Keychain, Windows Credential Manager).
  • Browser-saved passwords, and any passwords.xlsx / notes file / sticky note.
  • Backups, Recent Files, AutoRecover/temp copies, or a cloud trash/recycle bin.
  • Ask whoever created or sent the file — they likely set or know the password.

How it works

Everything runs inside this page, on your own machine. Your file is never uploaded anywhere — close the tab and it's gone.

  1. Drop the file. It auto-detects the lock type.
  2. PROTECTED (editing lock) → one click removes it and saves name-cleared.ext.
  3. ENCRYPTED (password-to-open) → add every clue about the owner, hit CRACK. On success the password pops up and you can save name-decrypted.ext — keeping the original extension.

Central dispatch — no password tried twice

Hitting RELEASE THE KRACKEN builds one de-duplicated master stream that merges every strategy below, then hands each unique candidate to exactly one instance — a pool of CPU cores plus the GPU if enabled. No password is ever tried on more than one instance, so every bit of compute goes to a *new* guess. Each live instance shows its own status line; the first to hit wins and kills the rest.

The strategies, merged in priority order (from "not guessing at all" to smart guessing):

  • Breached / reused — known, leaked and reused passwords tried verbatim. A lookup, not a guess — highest yield. Load a breach list (rockyou) or the owner's old passwords to supercharge it.
  • Clues + rules — your clues mangled: cases, leet (a→@), reversals, doubling, hundreds of suffixes/years.
  • Smart model (Markov) — a probabilistic model trained on real passwords; generates in likelihood order, not blindly.
  • Wordlist + rules, Combinator, Dates, Masks — the rest of the keyspace, de-duplicated against everything above.

Going faster

WebGPU acceleration (slider) runs the heavy hash loop for thousands of different candidates at once on your GPU — the real path toward 10,000+/sec (Office 2007 files; experimental). Prefer System GPU asks for your discrete/gaming GPU over the integrated one. The CPU pool always runs underneath as the reliable floor. For a strong password, Export Hash for GPU → hashcat is still the fastest route (millions/sec on a real GPU).

Use the Clue Finder tab to interview the client and load everything in one click. STOP / KILL terminates every instance instantly.

Honest truth: modern Office AES can't be bypassed — every tool (ours, hashcat, the $1,000 commercial ones) guesses and checks. The only non-guessing win is the Breached/reused lane or finding an existing copy. A long, random, unique password may simply be unrecoverable.

A long, random password may still be uncrackable here or on a GPU. If clues run out, the best move is often finding an un-passworded copy (email, OneDrive/SharePoint version history, a backup).

#!/usr/bin/env python3
"""
excel_unlock.py  —  Excel password toolkit for legitimate data recovery.

Covers BOTH kinds of Excel password protection:

  1. "diagnose" : tell you which kind of protection the file has.
  2. "strip"    : remove sheet / workbook *protection* (the editing lock).
                  This does NOT need a password. Instant. Works on .xlsx/.xlsm.
  3. "recover"  : recover the *open password* on an ENCRYPTED file by trying
                  a wordlist + smart mutations (names, dates, l33t, etc).
  4. "open"     : if you already know / recovered the password, write out a
                  clean decrypted copy.
  5. "hash"     : export the encryption hash so you can run it on hashcat/john
                  (GPU) if the Python attack isn't fast enough.

Only use this on files you own or are authorized to recover.

Usage:
  python3 excel_unlock.py diagnose  FILE.xlsx
  python3 excel_unlock.py strip     FILE.xlsx [-o OUT.xlsx]
  python3 excel_unlock.py recover   FILE.xlsx [--wordlist W.txt] [--hints a,b,c]
  python3 excel_unlock.py open      FILE.xlsx --password PW [-o OUT.xlsx]
  python3 excel_unlock.py hash      FILE.xlsx
"""
import argparse
import itertools
import os
import shutil
import sys
import zipfile
import re

# ---------------------------------------------------------------------------
# helpers
# ---------------------------------------------------------------------------

def _is_zip(path):
    """A real .xlsx is a ZIP. An encrypted file is an OLE2 compound file."""
    try:
        with open(path, "rb") as f:
            sig = f.read(8)
        return sig[:2] == b"PK"
    except OSError:
        return False


def _is_ole(path):
    with open(path, "rb") as f:
        sig = f.read(8)
    return sig == b"\xd0\xcf\x11\xe0\xa1\xb1\x1a\xe1"


# ---------------------------------------------------------------------------
# 1. diagnose
# ---------------------------------------------------------------------------

def cmd_diagnose(args):
    path = args.file
    if not os.path.exists(path):
        sys.exit(f"[!] File not found: {path}")

    if _is_ole(path):
        print("Result: ENCRYPTED  (Password-to-Open / 'Encrypt with Password')")
        print("  The whole file is encrypted. You cannot see any data without")
        print("  the password. Use:   recover   (to guess it)  or   hash  (GPU).")
        return

    if not _is_zip(path):
        print("Result: UNKNOWN format — not a standard .xlsx ZIP and not an")
        print("  encrypted OLE file. It may be an old .xls (BIFF) or corrupt.")
        return

    # It's a zip → inspect for protection tags.
    sheet_prot = []
    wb_prot = False
    with zipfile.ZipFile(path) as z:
        for name in z.namelist():
            if re.match(r"xl/worksheets/sheet\d+\.xml$", name):
                data = z.read(name).decode("utf-8", "replace")
                if "<sheetProtection" in data:
                    sheet_prot.append(name)
            if name == "xl/workbook.xml":
                data = z.read(name).decode("utf-8", "replace")
                if "<workbookProtection" in data:
                    wb_prot = True

    if sheet_prot or wb_prot:
        print("Result: PROTECTED  (editing lock — NOT encrypted)")
        print("  The data is readable; only editing is locked. No password")
        print("  needed to remove it. Use:   strip")
        if sheet_prot:
            print(f"  Protected sheets: {', '.join(sheet_prot)}")
        if wb_prot:
            print("  Workbook structure is protected.")
    else:
        print("Result: NO PASSWORD found. The file is a normal .xlsx with no")
        print("  sheet protection and no encryption. It should open freely.")


# ---------------------------------------------------------------------------
# 2. strip  (remove sheet / workbook protection, no password required)
# ---------------------------------------------------------------------------

def cmd_strip(args):
    path = args.file
    if not _is_zip(path):
        sys.exit("[!] This file is not a plain .xlsx ZIP. If 'diagnose' says it "
                 "is ENCRYPTED, use 'recover' instead — 'strip' cannot help.")

    out = args.output or _suffix(path, "-unlocked")
    tmp = out + ".tmp"
    removed = 0

    # Regexes for both self-closing <... /> and paired <sheetProtection>...</>
    pat_sheet = re.compile(r"<sheetProtection\b[^>]*/>|<sheetProtection\b.*?</sheetProtection>", re.S)
    pat_wb = re.compile(r"<workbookProtection\b[^>]*/>|<workbookProtection\b.*?</workbookProtection>", re.S)

    with zipfile.ZipFile(path) as zin, zipfile.ZipFile(tmp, "w", zipfile.ZIP_DEFLATED) as zout:
        for item in zin.infolist():
            data = zin.read(item.filename)
            if re.match(r"xl/worksheets/sheet\d+\.xml$", item.filename):
                text = data.decode("utf-8", "replace")
                new, n = pat_sheet.subn("", text)
                removed += n
                data = new.encode("utf-8")
            elif item.filename == "xl/workbook.xml":
                text = data.decode("utf-8", "replace")
                new, n = pat_wb.subn("", text)
                removed += n
                data = new.encode("utf-8")
            zout.writestr(item, data)

    shutil.move(tmp, out)
    if removed:
        print(f"[+] Removed {removed} protection block(s).")
        print(f"[+] Unlocked file written to: {out}")
    else:
        print("[i] No protection tags were present. Copied file to:", out)
        print("    (If the file actually prompts for a password to OPEN, it is")
        print("     ENCRYPTED — run 'recover' instead.)")


# ---------------------------------------------------------------------------
# 3 / 4 / 5 — encrypted-file operations (need msoffcrypto)
# ---------------------------------------------------------------------------

def _need_msoffcrypto():
    try:
        import msoffcrypto  # noqa
        return msoffcrypto
    except ImportError:
        sys.exit("[!] This action needs 'msoffcrypto-tool'.\n"
                 "    Install it with:  pip3 install msoffcrypto-tool")


def _try_password(path, password):
    """Return True if password decrypts the file."""
    import msoffcrypto
    import io
    with open(path, "rb") as f:
        off = msoffcrypto.OfficeFile(f)
        try:
            off.load_key(password=password)
            buf = io.BytesIO()
            off.decrypt(buf)      # raises on wrong password
            return True
        except Exception:
            return False


def cmd_open(args):
    _need_msoffcrypto()
    import msoffcrypto
    out = args.output or _suffix(args.file, "-decrypted")
    with open(args.file, "rb") as f:
        off = msoffcrypto.OfficeFile(f)
        off.load_key(password=args.password)
        with open(out, "wb") as g:
            off.decrypt(g)
    print(f"[+] Decrypted copy written to: {out}")


def cmd_hash(args):
    """Export a hashcat/john-compatible hash string via office2john if present,
    otherwise explain the fallback."""
    import subprocess
    for cand in ("office2john", "office2john.py"):
        exe = shutil.which(cand)
        if exe:
            subprocess.run([exe, args.file])
            print("\n[i] Feed the line above to hashcat (-m 9400/9500/9600 by "
                  "Office version) or John the Ripper.")
            return
    print("[i] 'office2john' is not installed in this environment.")
    print("    Get it from the John the Ripper 'jumbo' package (run/office2john.py),")
    print("    then:   office2john.py FILE.xlsx > hash.txt")
    print("    hashcat -m 9600 hash.txt wordlist.txt      # Office 2013+")
    print("    hashcat -m 9500 hash.txt wordlist.txt      # Office 2010")
    print("    hashcat -m 9400 hash.txt wordlist.txt      # Office 2007")


# ---------- candidate generation for 'recover' ----------

LEET = {"a": "@", "A": "@", "s": "$", "S": "$", "o": "0", "O": "0",
        "i": "1", "I": "1", "e": "3", "E": "3"}
SUFFIXES = ["", "1", "12", "123", "1234", "!", "!!", "@", "#", "01",
            "2020", "2021", "2022", "2023", "2024", "2025", "2026", "00", "99"]


def _mutations(word):
    word = word.strip()
    if not word:
        return
    seen = set()

    def emit(w):
        if w and w not in seen:
            seen.add(w)
            return True
        return False

    bases = {word, word.lower(), word.upper(),
             word.capitalize(), word.title()}
    # light l33t on the lowercase base
    leeted = "".join(LEET.get(c, c) for c in word.lower())
    bases.add(leeted)
    for b in bases:
        for suf in SUFFIXES:
            cand = b + suf
            if emit(cand):
                yield cand


def _candidate_stream(wordlist_path, hints):
    # 1. hints and their mutations first — most likely to hit.
    for h in hints:
        for m in _mutations(h):
            yield m
    # 2. wordlist + mutations
    if wordlist_path and os.path.exists(wordlist_path):
        with open(wordlist_path, "r", encoding="utf-8", errors="ignore") as f:
            for line in f:
                for m in _mutations(line):
                    yield m


def cmd_recover(args):
    _need_msoffcrypto()
    if not _is_ole(args.file):
        sys.exit("[!] This file is NOT encrypted (no open-password). "
                 "If editing is locked, use 'strip' instead.")

    hints = [h for h in (args.hints.split(",") if args.hints else []) if h.strip()]
    wl = args.wordlist
    if not wl and not hints:
        default = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                               "wordlists", "common.txt")
        if os.path.exists(default):
            wl = default
            print(f"[i] No wordlist/hints given — using built-in: {wl}")

    print("[i] Starting recovery. Press Ctrl-C to stop; progress prints every 200.")
    tried = 0
    try:
        for cand in _candidate_stream(wl, hints):
            tried += 1
            if tried % 200 == 0:
                print(f"    ...{tried} tried (last: {cand!r})")
            if _try_password(args.file, cand):
                print("\n[+] ================= PASSWORD FOUND =================")
                print(f"[+]   {cand!r}")
                print(f"[+]   (after {tried} attempts)")
                print("[+] Decrypt it with:")
                print(f'      python3 excel_unlock.py open "{args.file}" '
                      f'--password "{cand}"')
                return
        print(f"\n[-] Exhausted all candidates ({tried} tried). No match.")
        print("    Next steps: add more --hints, a bigger --wordlist, or export")
        print("    the hash ('hash' command) and run it on a GPU with hashcat.")
    except KeyboardInterrupt:
        print(f"\n[i] Stopped by user after {tried} attempts.")


# ---------------------------------------------------------------------------

def _suffix(path, suf):
    root, ext = os.path.splitext(path)
    return f"{root}{suf}{ext}"


def main():
    p = argparse.ArgumentParser(description="Excel password toolkit (legit recovery).")
    sub = p.add_subparsers(dest="cmd", required=True)

    d = sub.add_parser("diagnose", help="Identify which protection the file has.")
    d.add_argument("file")
    d.set_defaults(func=cmd_diagnose)

    s = sub.add_parser("strip", help="Remove sheet/workbook protection (no pw).")
    s.add_argument("file")
    s.add_argument("-o", "--output")
    s.set_defaults(func=cmd_strip)

    r = sub.add_parser("recover", help="Guess the open-password of an encrypted file.")
    r.add_argument("file")
    r.add_argument("--wordlist")
    r.add_argument("--hints", help="Comma-separated likely words: names, company, dates.")
    r.set_defaults(func=cmd_recover)

    o = sub.add_parser("open", help="Decrypt with a known password.")
    o.add_argument("file")
    o.add_argument("--password", required=True)
    o.add_argument("-o", "--output")
    o.set_defaults(func=cmd_open)

    h = sub.add_parser("hash", help="Export hash for hashcat/john (GPU).")
    h.add_argument("file")
    h.set_defaults(func=cmd_hash)

    args = p.parse_args()
    args.func(args)


if __name__ == "__main__":
    main()
