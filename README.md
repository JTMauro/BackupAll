# BackupAll: Claude backup

Start here to review your Claude work or rebuild any of it.

| Folder | What's in it | How to restore |
| --- | --- | --- |
| `SESSIONS-INDEX.md` | Every cloud Claude Code session: dates, final state, open items | Click through to each session's file |
| `sessions/` | One file per session: goal, decisions, links, final state, and your messages word for word | Paste the file into a new session and say "continue from here" |
| `artifacts/` | Full source of every artifact (`index.html` plus its files) and every Doc (`doc.md`) | Open `index.html` offline, or ask Claude to republish it. `MANIFEST.md` lists all of them |
| `app/ClaudeVault/` | Windows app that backs up your PC and mirrors this repo on a schedule | Run `INSTALL Claude Vault.cmd` |
| `pc/` | Created by Claude Vault: Claude Code sessions and claude.ai exports from your PC | Claude Vault > Restore |

The master index in Claude: https://claude.ai/artifact/QBahUjAzjftw6EFWWAo5jv

A weekly Claude task (Sundays at 7:47 PM Pacific) adds new sessions and artifacts to this repo.
